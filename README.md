# -telegram
必要条件：大陆+86手机号（可以接短信）gmail邮箱（要用google play）有科学上网的环境，安卓手机环境

我将使用BlueStack 安卓11 举例
1.下载必要软件
  Google Chome
  Google play

  在Google play中下载Googleg mail telegram X（注意不是telegram）

2.登录gmail，使整个手机可以登录Google账户

3.在telegram X中按照流程正常注册。此时是可以正常接收短信的。

4.注册成功后
在telegram X中打开设置——设备——扫描二维码。此时就可以正常扫描telegram的二维码了
此时可以扫描网页端，win11，app端
